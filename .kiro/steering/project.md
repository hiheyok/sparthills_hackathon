# SupplyLine: project steering

SupplyLine helps a household find open stores with stock during a disaster, and a safe alternative when an item is out. It is a hackathon project (SpartHill Hacks 2026, AWS Track). Amazon Bedrock must do real work inside the app.

## Rules that must not be broken

1. **Code decides facts, the model decides language.** Distance, hours, stock, routing and safety policy live in `app/engine.py`. The model (`app/ai.py`) understands requests, picks substitutes and writes text. Never ask the model for a distance, an opening time or a stock count.
2. **Safety policy is enforced in code.** Every catalog item has `policy` of `free`, `caution` or `none`. Items with `none` are never substituted. Items with `caution` can only use their `safe_subs` allowlist, which may be empty. Validate model output in `ai._alt_validator` and again in `engine.build_plan`. Never trust a verdict from the client.
3. **Never present rules output as AI.** If a stage falls back, its trace says `mode: rules` and why. The UI must keep saying so.
4. **The model may only use catalog item IDs** and only substitutes that are in stock nearby.
5. **Keep the 911 safety net** (`URGENT_PATTERNS` in `ai.py`) independent of the model.
6. **No secrets and no personal data in code, logs or the front end.**
7. **Demo data is fictional.** Never describe it as real inventory.

8. **The browser only talks to our own function** (plus OpenStreetMap map tiles). Third-party services such as road routing (`app/roads.py`) are called from the Lambda, never directly from the page, and must fail soft: the app keeps working without them. Keep the CSP `connect-src 'self'`.

## Layout

* `app/handler.py` Lambda entry, `app/engine.py` logic, `app/ai.py` Bedrock, `app/roads.py` road route for the map, `app/store.py` reports, `app/static/` front end (vanilla JS, no build).
* `app/data/*.json` is generated by `scripts/gen_data.py` (seed 2026). Edit the script and regenerate, do not hand-edit the JSON.
* `infra/template.yaml` CloudFormation. Keep it passing `cfn-lint`.
* `local_server.py` runs the same handler locally. `--ai off` needs no AWS.

## Commands

* Tests: `python3 -m unittest discover -s tests -p "test_*.py"`
* Local: `python3 local_server.py --ai off` then open http://localhost:8080
* Deploy: `bash scripts/deploy.sh`, then `python3 scripts/smoke.py <url>` (fails if any stage fell back)
* Remove: `bash scripts/destroy.sh`

## Style

* Python 3.12, standard library first. boto3 is provided by the Lambda runtime, so do not bundle it.
* Front end: no framework, no CDN, no inline scripts (the CSP blocks them). Escape everything inserted into the page.
* Plain language in the UI, readable by a stressed person on a phone.
* Add a test for every bug that is fixed, especially anything touching the safety policy.

## Model chain

Claude Haiku 4.5 (`us.anthropic.claude-haiku-4-5-20251001-v1:0`), then Nova 2 Lite (US profile, then in region), then Nova Lite. Override with `BEDROCK_MODEL_IDS`. Region is us-east-1.
